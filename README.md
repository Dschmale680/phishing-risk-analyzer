# Phishing Risk Analyzer

This beginner-friendly Python program asks questions about a suspicious email
and rates its phishing risk as **low**, **medium**, or **high**.

## Run it

From this directory, run:

```bash
python3 phishing_risk_analyzer.py
```

Answer each question with `y` or `n`. The program uses common warning signs,
such as urgent requests, suspicious links, and requests for passwords or
payment. This is a quick guide, not a guarantee that an email is safe.
